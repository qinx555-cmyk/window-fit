# 窗口随屏 · WindowFit

A lightweight macOS menu bar app that fits window width after dragging between displays.

把窗口从横屏拖到竖屏，松手后自动缩窄过宽的窗口，并把左右越界的部分移回目标屏幕。适合横屏与竖屏混用，也支持其他多屏排列。

## 窗口行为

- 以松手时鼠标所在的屏幕为目标，按其可用区域计算宽度，避开菜单栏和 Dock。
- 过宽的窗口缩到目标屏幕的可用宽度，较窄的窗口保持原宽度。左右越界时调整水平位置。
- 调整以松手后的窗口状态为准，保留该状态的高度和垂直位置，方便继续手动调整高度。
- 同屏移动、拖动网页内容和手动拉伸窗口边框不触发适配。

例如，1440×660 点的窗口拖到可用宽度为 1080 点的竖屏后，会变为 1080×660 点。

## 从源码构建与安装

需要 macOS 13 或更高版本，以及 Apple Command Line Tools 或 Xcode。应用使用 Swift、AppKit 和系统辅助功能 API，没有第三方依赖。缺少工具链时可运行 `xcode-select --install` 安装 Command Line Tools。

在项目目录中运行

```bash
./build.sh --test
./build.sh
```

构建脚本为当前 Mac 的处理器架构生成 `build/窗口随屏.app`，同时输出 `build/窗口随屏.zip`。

首次安装到当前用户的“应用程序”文件夹并启动

```bash
mkdir -p "$HOME/Applications"
ditto --norsrc --noextattr "build/窗口随屏.app" "$HOME/Applications/窗口随屏.app"
open "$HOME/Applications/窗口随屏.app"
```

更新前先从菜单栏退出“窗口随屏”，再复制新版本。保持安装路径固定，辅助功能授权和登录项都指向此处的副本。

## 首次授权

在“系统设置 → 隐私与安全性 → 辅助功能”中打开“窗口随屏”。列表中没有时，点按“+”并选择 `~/Applications/窗口随屏.app`。授权后检查菜单栏双屏图标，状态应为“已启用”；如果仍无反应，退出并重新打开应用。[Apple 辅助功能授权说明](https://support.apple.com/zh-sg/guide/mac-help/mh43185/mac)

应用在本机运行，无需联网，不需要屏幕录制权限。

构建脚本使用临时签名（ad hoc），产物未经 Apple 公证。下载到其他 Mac 使用时可能出现系统安全提示，源码构建会生成适合当前 Mac 的本机版本。重新构建或替换应用后，macOS 可能不再认可旧版本的授权，即使系统设置中的开关看起来仍然开启。此时退出应用，在“辅助功能”列表中移除旧条目，再用“+”添加安装后的新副本、打开权限并重新启动。

## 日常使用与登录启动

启动后，点击菜单栏的双屏图标可以查看状态，选择“暂停”“继续”或“退出窗口随屏”。仅连接一块屏幕时显示“等待第二块屏幕”。

需要随登录启动时，前往“系统设置 → 通用 → 登录项与扩展”（部分版本名为“登录项”），在“登录时打开”中添加 `~/Applications/窗口随屏.app`。添加登录项用于下次登录；本次使用仍需手动打开应用。[Apple 登录项设置说明](https://support.apple.com/zh-cn/guide/mac-help/mh15189/27/mac/27)

## 已知限制

- 应用设定的最小宽度可能大于屏幕可用宽度。这时会尽量让窗口左边对齐目标屏幕，右侧仍可能超出。
- 固定宽高比的窗口可能在缩窄时连带改变高度。检测到这种情况后，窗口随屏会尝试恢复原尺寸，再调整水平位置。
- 全屏窗口、非标准窗口，以及不允许辅助功能调整大小或位置的窗口，可能无法适配。
- 跨屏拖动依赖目标应用自身先完成移动。部分应用的自定义标题栏存在拖不动或拖动区域变化的情况，窗口随屏无法替它开始拖动。全屏切换、系统菜单移屏等操作也不属于鼠标跨屏拖放。
- 为兼容 ChatGPT 等部分应用跨屏后暂时保留旧宽度的情况，程序在松手约 120 毫秒后调整，必要时再等约 220 毫秒重试一次。重试仅在窗口仍过宽、位置和高度符合检查条件时执行；新的鼠标手势会取消旧重试。

## 代码与验证

`./build.sh --test` 运行窗口几何检查，覆盖横竖屏、负坐标、侧边 Dock、水平越界和拖动边界等情况。辅助功能权限和应用兼容性还需在实际双屏环境中验证。

- [WindowFitApp.swift](Sources/WindowFitApp.swift) 管理菜单栏、屏幕识别、拖放检测和延迟重试。
- [WindowFitPolicy.swift](Sources/WindowFitPolicy.swift) 计算目标宽度与水平位置。
- [WindowAccess.swift](Sources/WindowAccess.swift) 通过辅助功能读取和调整窗口。
